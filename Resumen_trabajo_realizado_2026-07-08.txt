11. Nuevo rol DVSO: jefatura_ops

- Se creó un rol nuevo:
  - `jefatura_ops`
- Este rol es únicamente para DVSO.
- Además, solo interviene en el proceso:
  - `DVSO-OPS-805`

Funcionamiento del rol:

- Puede entrar a Revisión.
- Puede entrar a Búsqueda.
- Solo ve procesos DVSO-OPS-805 asignados.
- Cuando Jefatura DVSO envía un DVSO-OPS-805 a la siguiente etapa, se envía a `jefatura_ops`.
- Para los demás procesos DVSO, se sigue enviando a `inspector_dvso`.
- `jefatura_ops` puede:
  - Revisar el proceso 805 asignado.
  - Devolverlo a Jefatura DVSO.
  - Devolverlo al usuario para corrección.
- El backend bloquea que `jefatura_ops` intervenga en otros trámites DVSO.
- Se agregó al administrador para poder crear usuarios con ese rol.
- Se corrigió el problema de "Rol no válido" agregando explícitamente `jefatura_ops` en roles permitidos.
- Se aclaró que después de este cambio se debe reiniciar el backend para que tome el rol nuevo.
