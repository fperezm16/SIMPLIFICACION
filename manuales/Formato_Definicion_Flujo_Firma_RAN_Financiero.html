7. Ejemplo propuesto para RAN

Sujeto a confirmación de RAN.

  1. Recepción asigna la solicitud al analista RAN.
  2. El analista revisa y prepara el PDF final.
  3. El analista envía al aprobador.
  4. El aprobador autoriza el trámite.
  5. El sistema habilita Solicitar firma electrónica.
  6. El firmante revisa y firma.
  7. El sistema conserva el PDF, registra auditoría y notifica.
  8. Recepción entrega el documento.

RAN debe confirmar: si el aprobador también firma; si la firma ocurre antes o después de aprobar; ubicación de la firma; responsable de correcciones y entrega.

8. Ejemplo propuesto para Financiero

Sujeto a confirmación de Financiero.

  1. El analista revisa la solicitud.
  2. Traslada el expediente al emisor.
  3. El emisor prepara el documento definitivo.
  4. El aprobador autoriza el contenido.
  5. El proceso regresa al emisor o firmante designado.
  6. El sistema habilita Solicitar firma electrónica.
  7. El sistema conserva el PDF firmado y notifica.

Financiero debe confirmar: quién firma; si el pago debe estar aprobado; qué trámites requieren firma; quién entrega el documento y qué ocurre ante rechazo.

10. Criterios mínimos para implementar

  • Punto exacto donde aparece Solicitar firma.
  • Rol solicitante y rol firmante.
  • Documento y ubicación visual de la firma.
  • Estados anterior, durante y posterior.
  • Comportamiento ante rechazo, error o vencimiento.
  • Notificaciones y responsable de entrega final.
